# KidsTown-JS
An AI-assisted translation of the original Perl script found in the 1998 release of the KidsTown website.

An in-progress version of this webpage is available at...

https://gage53211.github.io/KidsTown-JS/

### Project Description
The goal of this project is to convert an older interactive website from server-based CGI to browser-based JavaScript
The original KidsTown website was built using Perl CGI and relied on server-side processing. Our goal is to recreate the website using client-side JavaScript while preserving the functionality and overall appearance of the original site.

### Original Source
Website Source: https://github.com/MetroCS/kidstown_cgi

## Project Constraints
The replacement website:
- Must use no server-side processing
- Must contain no Perl or CGI dependencies
- Must be deployable using GitHub Pages
- Should avoid JavaScript frameworks
